# Sistema de Cadastro Java

Sistema de cadastro de pessoas desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## Sobre o projeto

O sistema permite realizar o gerenciamento básico de pessoas através de um menu interativo no terminal.

O usuário pode cadastrar, listar, buscar, editar e remover pessoas cadastradas.

## Funcionalidades

* Cadastro de pessoas
* Listagem de pessoas cadastradas
* Busca de pessoas pelo nome
* Edição de dados de pessoas
* Remoção de pessoas
* Menu interativo no terminal

## Conceitos aplicados

* Programação Orientada a Objetos (POO)
* Classes e objetos
* Construtores
* Encapsulamento
* Métodos
* ArrayList
* Estruturas de repetição
* Estruturas condicionais

## Como executar

Compile os arquivos Java:

```bash
javac src/*.java
```

Execute o programa:

```bash
java -cp src Program
```
